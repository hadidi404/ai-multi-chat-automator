# Contributor notes

Guidance for anyone — human or AI assistant — working in this repository.

## Commits and pull requests

- **Never add co-author, "generated by", or assistant attribution trailers** to
  commit messages, pull requests, or code comments. Commits are authored by the
  repository owner alone.
- Write commit subjects in the imperative mood, under 72 characters, with no
  trailing period: `Add domain check to sign-in`, not `Added...` or `Adding...`.
- Explain *why* in the body when the reason is not obvious from the diff. Wrap
  at 72 characters. Skip the body for genuinely trivial changes.
- One logical change per commit.
- Never commit `drive-client.json`, `drive-config.json`, `user-data/`, or
  anything under `dist/`. They hold credentials, live sessions, or build output.

## Code style

- CommonJS modules, `'use strict'` at the top of every file.
- Two-space indent, single quotes, semicolons, trailing commas in multi-line
  literals.
- JSDoc on exported functions: one-line summary plus `@param` / `@returns`.
- Comment sparingly, and only to explain reasoning that the code cannot show —
  a browser quirk, a deliberate trade-off. Do not narrate what the code does.
- Prefer clear names over explanatory comments.

## Architecture

```
server.js         HTTP server, SSE progress stream, request routing
electron/         Desktop shell and auto-update
bots/             One module per AI site: selectors and a run() function
utils/            Browser session, answer parsing, Drive upload, logging
public/           Single-page UI
tools/            Development utilities, excluded from the build
```

Data written at runtime (browser profile, saved questions, screenshots,
credentials) resolves through `utils/paths.js`. Never write next to the source:
those paths are read-only in a packaged build.

## Before committing

```bash
npm run check     # syntax check every source file
```

Selectors in `bots/` break when the AI sites change their markup.
`node tools/inspect.js <bot> "<question>"` reports what each selector currently
matches.
